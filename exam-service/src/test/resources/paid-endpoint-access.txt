# B13b: every endpoint of paid open exams (com.examportal.paid) and who may reach it. PaidEndpointRegistryTest fails when
# an endpoint is missing here, a line names no endpoint, or the real security chains (PaidSecurityConfig before the
# unchanged SecurityConfig, the real JWT filters, real tokens) together with @PreAuthorize let other callers through.
#
#   PUBLIC      everybody: the catalog, the providers' notifications (their signature decides), the sandbox page (its
#               own signed link and PAYMENTS_SANDBOX_ALLOWED decide)
#   GUEST_ONLY  a guest token only; no account token of any role
#   ADMIN_ONLY  an ADMIN account token only (never a guest)
#
