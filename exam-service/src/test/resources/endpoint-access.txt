# B13: every endpoint of exam-service and who may reach it. EndpointRegistryTest fails when an endpoint is missing
# here, when a line names an endpoint that no longer exists, and when the roles the security chain and @PreAuthorize
# really let through differ from the class.
#
#   ADMIN_ONLY    ADMIN
#   OWNER_SCOPED  ADMIN everything, INSTRUCTOR only the own exams, sessions, groups, members, media (404 otherwise)
#   OWN_DATA      every signed-in user, only what belongs to the caller or what the caller may take part in
#   STUDENT_ONLY  the participant's flow (available exams, start, answer, submit, result, join): every signed-in user
#                 acts as a participant on the own sessions and requests only
#   PUBLIC        no sign-in (nothing private in the answer)
#   INTERNAL      /internal/**, service to service: shared secret, 404 without it
#
# Method, path (path variables without their regex), class
